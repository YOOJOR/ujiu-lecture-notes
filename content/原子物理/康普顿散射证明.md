# 康普顿散射公式的相对论严格推导

## 1. 物理模型与状态设定
将光子和电子看作独立粒子。在**实验室坐标系**中，设碰撞前电子静止。

* **碰撞前（Initial State）：**
  * **入射光子：** 能量 $E = h\nu$，动量大小 $p = \frac{h\nu}{c}$，方向单位向量为 $\hat{n}$。
  * **静止电子：** 能量 $E_e = m_0c^2$，动量 $\vec{p}_e = 0$。

* **碰撞后（Final State）：**
  * **散射光子：** 能量 $E' = h\nu'$，动量大小 $p' = \frac{h\nu'}{c}$，方向单位向量为 $\hat{n}'$。
  * **反冲电子：** 能量 $E_e'$，动量为 $\vec{p}_e'$。
  * **散射角 $\phi$：** 光子碰撞前后的方向夹角，满足 $\hat{n} \cdot \hat{n}' = \cos\phi$。

---

## 2. 守恒定律列式
根据**能量守恒**和**动量守恒**，将反冲电子的物理量单独留在等式一边：

### 能量守恒
$$E_e' = h\nu + m_0c^2 - h\nu' = h(\nu - \nu') + m_0c^2 \quad \text{--- (1)}$$

### 动量守恒
$$\vec{p}_e' = \frac{h\nu}{c}\hat{n} - \frac{h\nu'}{c}\hat{n}' \quad \text{--- (2)}$$

---

## 3. 利用相对论不变量消元
利用爱因斯坦相对论能量-动量关系，消除反冲电子的变量 $E_e'$ 和 $\vec{p}_e'$：
$$(E_e')^2 - (\vec{p}_e')^2 c^2 = m_0^2c^4 \quad \text{--- (3)}$$

### 3.1 计算 $(E_e')^2$
将式 (1) 展开：
$$(E_e')^2 = \left[ h(\nu - \nu') + m_0c^2 \right]^2 = h^2(\nu - \nu')^2 + 2m_0c^2h(\nu - \nu') + m_0^2c^4 \quad \text{--- (4)}$$

### 3.2 计算 $(\vec{p}_e')^2 c^2$
将式 (2) 做向量自乘（点积），并乘以 $c^2$：
$$(\vec{p}_e')^2 c^2 = \left( \frac{h\nu}{c}\hat{n} - \frac{h\nu'}{c}\hat{n}' \right)^2 \cdot c^2 = h^2\nu^2(\hat{n}\cdot\hat{n}) + h^2(\nu')^2(\hat{n}'\cdot\hat{n}') - 2h^2\nu\nu'(\hat{n}\cdot\hat{n}')$$
代入 $\hat{n}\cdot\hat{n} = 1$ 和 $\hat{n}\cdot\hat{n}' = \cos\phi$：
$$(\vec{p}_e')^2 c^2 = h^2\nu^2 + h^2(\nu')^2 - 2h^2\nu\nu'\cos\phi \quad \text{--- (5)}$$

---

## 4. 联立化简与消项
将式 (4) 和式 (5) 代入核心关系式 (3) 中：
$$\left[ h^2(\nu - \nu')^2 + 2m_0c^2h(\nu - \nu') + m_0^2c^4 \right] - \left[ h^2\nu^2 + h^2(\nu')^2 - 2h^2\nu\nu'\cos\phi \right] = m_0^2c^4$$

两边同时消去静止能量项 $m_0^2c^4$，并将第一项展开化简：
$$\left( h^2\nu^2 + h^2(\nu')^2 - 2h^2\nu\nu' \right) + 2m_0c^2h(\nu - \nu') - h^2\nu^2 - h^2(\nu')^2 + 2h^2\nu\nu'\cos\phi = 0$$

消去二阶平方项 $h^2\nu^2$ 和 $h^2(\nu')^2$，只留下交叉项：
$$-2h^2\nu\nu' + 2h^2\nu\nu'\cos\phi + 2m_0c^2h(\nu - \nu') = 0$$

移项并提取公因式：
$$2m_0c^2h(\nu - \nu') = 2h^2\nu\nu'(1 - \cos\phi)$$

两边约去 $2h$：
$$m_0c^2(\nu - \nu') = h\nu\nu'(1 - \cos\phi)$$

---

## 5. 转换为波长形式（最终结论）
两边同除以 $m_0c^2\nu\nu'$：
$$\frac{\nu - \nu'}{\nu\nu'} = \frac{h}{m_0c^2}(1 - \cos\phi) \implies \frac{1}{\nu'} - \frac{1}{\nu} = \frac{h}{m_0c^2}(1 - \cos\phi)$$

代入波长与频率的关系 $\frac{1}{\nu} = \frac{\lambda}{c}$，等式两边同乘以 $c$：

> [!important] **康普顿散射波长公式**
> $$\Delta \lambda = \lambda' - \lambda = \frac{h}{m_0c}(1 - \cos\phi)$$

其中，电子的康普顿波长定义为：
$$\lambda_c = \frac{h}{m_0c} \approx 2.426 \times 10^{-3} \text{ nm}$$
