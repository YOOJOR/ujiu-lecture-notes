这里主要研究简单的双原子分子

分子运动状态，分三部分描述
- **电子** electronic 的运动 $E_{e}$ 1~20 eV
- 分子中原子之间**振动** vibration $E_{v}$ 0.05~1 eV
- 分子**转动** rotation  $E_{r}$ 10 的-2到~-4 次方 eV
电子能级>振动能级>转动能级，且可包含嵌套

## 双原子分子电子态
### 轨道角动量
$m_{l}$ 代表电子的运动状态，在分子中，考虑能量，只用 $\lambda = |m_{l}|$ 来表示电子的能量即可
>  正负两种情况表示相同的能量

| $\lambda$ | 1        | 2     | 3        | 4      |
| --------- | -------- | ----- | -------- | ------ |
| 电子态名称     | $\sigma$ | $\pi$ | $\delta$ | $\phi$ |
#### 分子的电子态
分子的总轨道角动量（所有外层电子在轴上的分量之和）用 $\Lambda = |\sum m_{l}|$ 表示

同样，取绝对值是因为正负方向对应相同的能量

| $\Lambda$ | 0        | 1     | 2        | 3      |
| --------- | -------- | ----- | -------- | ------ |
| 分子态名称     | $\Sigma$ | $\Pi$ | $\Delta$ | $\Phi$ |
### 电子自旋
所有电子正常自旋，有角动量，有总自旋量子数 $S$
$\Lambda \neq 0$ 时，电子自旋在电子轨道运动产生的磁场中产生自旋角动量，总自旋角动量投影分量 
$$
	\Sigma = S, S-1,\dots, -S
$$
先确定了 S，再确定 $\Sigma$

$\Lambda=0$ 的时候，就没有电子自旋的能量分裂，尽管 $\Sigma$ 是不同的值，他们的能量也是一样的

### 总角动量
$\Omega = |\Lambda+\Sigma|$

## 转动
![[attachments/atom9-3.png]]
 经典力学模型中
**转动能量**：$E = \frac{1}{2}I\omega^2 = \frac{P^2}{2I}$
**转动惯量**：$I = \mu r^2$ ，其中约化质量 $\mu = \frac{m_1 m_2}{m_1 + m_2}$

量子力学模型中角动量量子化，$P = \sqrt{J(J+1)}\frac{h}{2\pi}$，带入经典力学的转动能量中得 $$E = \frac{h^2}{8\pi^2 I} J(J+1)$$
- 非刚体修正：$E = hc[BJ(J+1) - DJ^2(J+1)^2]$
- $B=\frac{E}{hc}=\frac{h}{8\pi^{2} Ic}$
### 纯转动光谱
![[attachments/atom9-4.png]]
- **选择定则**：$\Delta J = \pm 1$
- **谱线波数**：$\tilde{\nu} = 2B(J+1)$ (或 $\tilde{\nu} = 2BJ'$，其中 $J'=1, 2, 3 \dots$)
- **转动常数**：$B = \frac{h}{8\pi^2 Ic}$
- **特征**：纯转动谱谱线波数间隔相等，位于远红外或微波波段
### 振动-转动光谱
![[attachments/atom9-5.png|178]]
- **跃迁能量**：$\tilde{\nu} = \tilde{\nu}_0 + B'[J'(J'+1)] - B[J(J+1)]$
- **选择定则**：$\Delta J = \pm 1$
- **R 支** ($\Delta J = +1$)：$\tilde{\nu} = \tilde{\nu}_0 + 2BJ'$ ($J'=1, 2, 3 \dots$)
- **P 支** ($\Delta J = -1$)：$\tilde{\nu} = \tilde{\nu}_0 - 2BJ$ ($J=1, 2, 3 \dots$)

> [!note] 简化
> 这里做了简化，认为 B 和 B‘是几乎相同的

### 电子-振动-转动谱带
- **波数公式**：$\tilde{\nu} = \tilde{\nu}_0 + B'J'(J'+1) - BJ(J+1)$
- **选择定则**：$\Delta J = 0, \pm 1$ ($J'=0 \rightarrow J=0$ 除外)
- **谱线分支**：
    - **P 支** ($J'=J-1$)：$\tilde{\nu} = \tilde{\nu}_0 - (B'+B)J + (B'-B)J^2$
    - **Q 支** ($J'=J$)：$\tilde{\nu} = \tilde{\nu}_0 + (B'-B)J + (B'-B)J^2$
    - **R 支** ($J'=J+1$)：$\tilde{\nu} = \tilde{\nu}_0 + (B'+B)J' + (B'-B)J'^2$

## 拉曼散射 $$\tilde{\nu}' - \tilde{\nu}_0 = \pm (6 + 4n)B$$
**现象:** 光穿过透明介质，散射光谱线波数发生了变化，增加或者减少了某个数值，且改变量为两固定数值的组合，所以也称组合散射，又称拉曼散射或者拉曼效应。

- 散射光波数 = 入射光波数 $\pm$ 固定数值。
- 这个“固定数值”（即差值 $\Delta\tilde{\nu}$）**与光源无关，只决定于散射物本身**
### 规律
大间距谱线：$\tilde{\nu}' = \tilde{\nu}_0 \pm \tilde{\nu}_1$
小间距谱线：$\tilde{\nu}' - \tilde{\nu}_0 = \pm (6 + 4n)B$

大间距谱线原理：振动能级的变动 ![[attachments/atom9-6.png]]

小间距谱线的核心就是，$4B$ 和 $6B$ 是怎么来的
此时**跃迁能量**：$\tilde{\nu} = \tilde{\nu}_0 + B[J(J+1)] - B[J'(J'+1)]$,这里两个 $B$ 相同，$J$ 是跃迁前的能级，$J'$ 是跃迁后的能级
经过分析，我们发现，$\Delta J = 0,\pm 2$
若 $\Delta J = 2$,即 $J = J'+2$ 则 $$(J' + 2)(J' + 3) - J'(J' + 1) = (J'^2 + 5J' + 6) - (J'^2 + J') = 4J' + 6$$
同理 $J = J'-2$ 时，视作 $J' = J+2$ ，则相当于与上述过程差一个负号，结果带 $J$ 而不是 $J'$

综上得到 $$\tilde{\nu}' = \tilde{\nu}_0 + (4J' + 6)B$$$$\tilde{\nu}' = \tilde{\nu}_0 - (4J + 6)B$$ 注意这里理论上，J 和 J'都必须大于 0，而两个式子中出现的 J 都是约束条件中较小的那个，所以都可以从 0 开始取值。没问题，完美符合理论，解释了拉曼散射。

$\nu = n_1\nu_1 + n_2\nu_2 + n_3\nu_3 + \dots$
