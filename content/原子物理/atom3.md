# 第3章 量子力学初步 复习笔记

## 一、 早期量子论（光的波粒二象性与德布罗意波）

### 1. 黑体辐射

* **斯特藩—玻尔兹曼定律**：$R_0(T) = \sigma T^4$
* $R_0(T)$ 为辐照度/总辐射出射度，$\sigma$ 为斯特藩—玻尔兹曼常数。


* **维恩位移定律**：$\lambda_m T = b$
* $\lambda_m$ 为辐射黑体光谱辐射出射度极大值对应的波长，$b$ 为维恩常数。


* **普朗克公式**：$R_{0\lambda}(T) = \frac{2\pi hc^2}{\lambda^5} \frac{1}{e^{hc/\lambda k_B T} - 1}$
* $h$ 普朗克常数，$c$ 光速，$k_B$ 玻尔兹曼常数。



### 2. 光电效应

* **爱因斯坦的光量子理论公式**：$\frac{1}{2}mv_m^2 = h\nu - \phi$
* $\frac{1}{2}mv_m^2$ 为光电子的最大初动能，$\nu$ 为入射光频率，$\phi$ 为金属的逸出功。



### 3. 德布罗意物质波

* **波粒二象性关系式**：$\lambda = \frac{h}{p}$
* **实验验证**：戴维逊—革末实验、汤姆逊电子衍射实验（证实了微观粒子具有波动性）。

### 4. 海森堡不确定关系原理

* **位置与动量不确定关系**：$\Delta x \Delta p_x \ge \frac{\hbar}{2}$
* **能量与时间不确定关系**：$\Delta E \Delta t \ge \frac{\hbar}{2}$
* 约化普朗克常数 $\hbar = \frac{h}{2\pi}$。

## 二、 波函数与薛定谔方程

### 1. 波函数 $\psi(\vec{r}, t)$ 及其物理意义

* **物理意义（玻恩统计解释）**：波函数本身没有直接的物理意义，其模方 $|\psi(\vec{r}, t)|^2 = \psi^*(\vec{r}, t)\psi(\vec{r}, t)$ 表示 $t$ 时刻微观粒子在空间 $\vec{r}$ 点出现的**相对概率密度**。
* **标准化条件（物理要求）**：
1. **连续性**
2. **有限性**
3. **单值性**
4. **归一化条件**：$\iiint |\psi|^2 dxdydz = 1$（表示粒子在整个空间中出现的总概率为 1）。



### 2. 薛定谔方程

* **含时薛定谔方程**：$i\hbar \frac{\partial}{\partial t}\psi(\vec{r}, t) = \left[-\frac{\hbar^2}{2m}\nabla^2 + U(\vec{r}, t)\right]\psi(\vec{r}, t)$
* **定态（与时间无关）薛定谔方程**：$\left[-\frac{\hbar^2}{2m}\nabla^2 + U(\vec{r})\right]\psi(\vec{r}) = E\psi(\vec{r})$
* $\nabla^2$ 为拉普拉斯算符，$U$ 为势能，$E$ 为粒子总能量。

## 三、 典型一维定态问题

### 1. 无限深方势阱

* **粒子的能量量子化**：$E = E_n = \frac{\hbar^2\pi^2n^2}{2ma^2}$
* $a$ 为势阱宽度，$n = 1, 2, 3\cdots$ 为量子数（注意：$n$ 不能为 0）。



### 2. 隧道效应（势垒贯穿）

* **透射系数**：$D = D_0 e^{-2a\frac{\sqrt{2m(U-E)}}{\hbar}}$
* 表示当粒子能量 $E < U$（势垒高度）时，粒子仍有一定概率穿透宽度为 $a$ 的势垒。



### 3. 线性谐振子

* **能量本征值**：$E = \left(n + \frac{1}{2}\right)\hbar\omega, \quad (n = 0, 1, 2\cdots)$
* $\omega$ 为谐振子的角频率。当 $n=0$ 时，$E_0 = \frac{1}{2}\hbar\omega$ 称为**零点能**（微观粒子即使在绝对零度也具有能量）。

## 四、 氢原子结构与空间量子化

通过解氢原子的薛定谔方程，引入了三个空间几何方面的量子数：

### 1. 氢原子的能量量子化

* **能级公式**：$$E_n = -\frac{2\pi^2m_e e^4}{(4\pi\varepsilon_0)^2 h^2 n^2} = -\frac{m_e e^4}{8\varepsilon_0^2 h^2} \cdot \frac{1}{n^2}$$
* **主量子数**：$n = 1, 2, 3\cdots$ （决定氢原子能量的主要量子数）。

### 2. 氢原子的角动量量子化

* **角动量大小**：$L = \sqrt{l(l+1)}\hbar$
* **角动量量子数（轨道量子数）**：$l = 0, 1, 2\cdots (n-1)$ （共 $n$ 个取值，决定电子轨道的角动量大小）。

### 3. 氢原子角动的空间取向量子化

* **角动量在磁场方向的分量**：$L_z = m\hbar$
* **磁量子数**：$m = 0, \pm 1, \pm 2\cdots \pm l$
* **取向数目**：角动量在空间的取向只有 $(2l+1)$ 种可能（对应空间转向的离散化）。
